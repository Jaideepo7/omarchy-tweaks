# dotfiles
Personal Omarchy tweaks. Run `./install.sh` after any update/resync.
- hypr/: Hyprland Lua config (app keybinds: Super+Shift+W/A/Q/Z, Super+H)
- patches/calendar-timedrow.patch: fixes time/dot overlap in the calendar plugin
- patches/bar-hover-open.patch: hovering a bar icon for 0.5s opens its panel; it auto-closes when the pointer leaves unless clicked inside
